RUN LOCALLY
1. Install Node.js 18+
2. In this folder run: npm install
3. Run: npm start
4. Open: http://localhost:10000
5. Admin: http://localhost:10000/admin.html

SECURITY
Set a strong ADMIN_KEY environment variable before deployment. The included default is only for testing.

DEPLOYMENT
For Render: Build command = npm install; Start command = npm start; Environment variable = ADMIN_KEY.
IMPORTANT: Render's normal filesystem is ephemeral. The current demo stores orders and uploaded photos on disk, so for a real production store you should connect a persistent database and object storage before relying on it for long-term order records/photos.
